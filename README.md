# 🗄️ SQL Course — Learn SQL Simply

An interactive SQL course website built with Python & Flask.  
Write real SQL queries in your browser, see live results, and complete challenges.

## Features

- 10 lessons from Beginner to Advanced
- Live SQL editor with a real SQLite sandbox
- 50+ runnable examples
- 10 challenges with hints and solutions
- Reset sandbox database anytime
- Mobile-friendly dark UI

## Run Locally

```bash
pip install flask
python app.py
```

Then open http://localhost:5000
